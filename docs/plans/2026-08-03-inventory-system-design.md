# 独立商品库库存管理系统设计

系统使用 Next.js 14、TypeScript、Prisma、SQLite 与 Docker，独立于商品编码系统部署和存储。通过其 `/api/v1` 只读 API 同步 SKU 快照，永久以 `internalCode` 建立关联。

首版为无登录的单仓内网应用，包含商品同步、库存余额、扫码入库/出库、不可变库存流水、库存盘点、低库存预警和系统设置。默认每 15 分钟同步，也可手动立即同步。同步只更新商品快照，绝不改写库存历史。

所有库存变更都在数据库事务中同时写余额与流水。负库存策略支持严格禁止、允许并预警、超额二次确认三种模式，可在设置中切换。数据结构保留仓库实体，首版只初始化一个主仓库，为未来多仓扩展留出空间。
