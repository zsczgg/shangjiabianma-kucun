# 配置中心与统一扫码设计

## 页面结构

新增 `/configuration` 配置中心，集中管理负库存策略、全局低库存阈值、商品独立阈值、商品同步状态及 API Key。左侧导航以“配置中心”替代“系统设置”，旧 `/settings` 地址重定向至新页面。商品库存页只展示阈值及其来源，所有修改操作统一进入配置中心。

商品独立阈值区域支持按商品名、内部编码和厂家条码搜索；每个商品可设置独立阈值，也可恢复跟随全局默认值。

## 扫码输入

扫码出入库与库存盘点共用 `ScannerInput` 组件。组件仅接受可打印 ASCII 字符，使用 `lang="en"`、关闭拼写纠正，并监听输入法组合事件。检测到中文等非 ASCII 内容或输入法组合时，立即清空并提示切换英文输入法后重扫。由于浏览器不能修改操作系统输入法，系统通过拒绝异常内容保证乱码不会进入商品查询。

识别完成后扫码框清空并恢复焦点；数量输入框保持正常编辑，按回车提交或确认后焦点回到扫码框。盘点页重复扫描商品时不新增重复行，而是定位并高亮已有商品。

## 验证

为字符过滤函数添加单元测试；运行完整测试和生产构建；在浏览器中验证配置中心、两处扫码焦点、中文组合输入拦截、重复盘点扫码与数量输入行为。
