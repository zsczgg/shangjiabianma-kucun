# 北京时间与商品图片接入设计

## 时间

数据库继续以标准时间保存，所有展示统一通过 `Asia/Shanghai` 格式化，避免 Windows、Node 或 Docker 主机时区改变显示结果。页头增加客户端实时北京时间，每秒刷新；首页“今日流水”也按北京时间自然日计算。Docker 应用、同步进程和备份服务统一设置 `TZ=Asia/Shanghai`，使日志与备份文件名便于运维核对。

## 图片同步

编码系统 `/api/v1` 的 `product.imageUrl` 为可直接访问的完整地址，`product.imageSource` 为 `UPLOAD`、`URL` 或 `null`。库存系统以 `internalCode` 关联 SKU，同步保存这两个字段；无图片时均保存为空。原有商品和库存数据不受数据库扩展影响。

## 图片展示

建立统一商品缩略图组件，在商品库存、扫码出入库、库存盘点、低库存预警和配置中心展示。图片保持完整比例，不裁切；没有图片或加载失败时显示一致的占位图。盘点单保存图片地址快照仅用于当前界面展示，不改变库存流水数据结构。

## 验证

测试北京时间格式化和北京时间日期边界；执行 Prisma 迁移、商品同步测试、完整单元测试及生产构建；浏览器验证全局时钟、五个页面的缩略图/占位图和现有扫码流程。
